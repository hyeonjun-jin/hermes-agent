# Persona 실험 후속 수정 및 오프라인 검증

## 범위

`feat/persona-gpt4o-mini-validation`에서 프로토타입과 해당 테스트만 수정했다.
Hermes 코어, API 사용량 원장 구현, 12회 한도, 조건별 호출 제한과 자동 재시도 정책은
변경하지 않았다. main에는 병합하지 않는다. 이번 작업의 실제 OpenAI API 호출은 **0회**다.

이전 실제 실험의 8회 / 입력 35,484 / 출력 469토큰은 사용자 제공 기록이다.
이 환경에는 운영 원장과 실제 응답 JSON이 없으므로 이를 수정하거나 재실행하지 않았다.
Mock 호출의 토큰은 실제 사용량이 아니며, 테스트의 `real` 경로도 전송 함수를 스텁으로
대체한다. 테스트 원장은 임시 경로에만 만든다.

## 변경

- RAG의 검색 범위와 Environment의 현재 관측을 별도 출처로 기록한다.
- 확인된 프로젝트·단계·제약의 누락과 미확인 처리, 명시적 단계 충돌, 전역적 부재 주장을 검토한다.
- 근거 정정은 실제 조회된 값만 덧붙인다. 모델 초안은 남기고 검토 필요 표시를 한다.
- 표의 라벨이 명확하면 항목/내용, 그렇지 않으면 순서/내용으로 나눈다. 기존 다열 표는 유지한다.
- `<br>`, `<br/>`, `<BR />`는 표 안에서 행으로 나눈다. 임의 요약이나 숫자·날짜·문서 ID 변경은 하지 않는다.
- 모델 원문, 근거 보정 후 텍스트, 형식 보정 후 표시 답변과 감사 정보를 각각 기록한다.
- Streamlit은 과거 저장된 한 열 표도 화면에서 정리하며 DB 원본은 변경하지 않는다.

## 실행 환경

저장소 PM으로 테스트 환경을 만들고 `scripts/run_tests.sh`로 실행했다. Streamlit 검증에는
프로토타입의 고정 버전 1.67.0을 사용했다. 저장소 의존성 파일이나 lock은 변경하지 않았다.

이 컨테이너의 `/var/tmp`가 읽기 전용이라 기본 runner가 시작하지 못했다. 저장소 밖의
임시 실행 어댑터로 canonical runner의 scratch 위치만 쓰기 가능한 임시 디렉터리로
바꿨다. runner 소스, 테스트, 자격증명 제거와 네트워크 차단 기준은 변경하지 않았다.
어댑터는 커밋하지 않는다. 일반 개발 환경에서는 아래 명령을 그대로 실행하면 된다.

```bash
HERMES_PYTHON=<Streamlit이 포함된 테스트 Python> \
  scripts/run_tests.sh -j 3 tests/persona_prototype/ \
  tests/agent/test_memory_provider.py \
  tests/agent/test_memory_provider_caller_profile.py \
  tests/agent/test_memory_manager_fork_scope.py \
  tests/tools/test_delegate_toolset_scope.py -q
python scripts/check --base <수정 전 커밋>
```

## 테스트 결과

- 프로토타입 104개: Alice/Bob/Carol Mock, Research→Analysis→Verification,
  사용자별 Persona·Memory·Environment 격리, Fact Grounding, 원장/호출 제한,
  원응답/보정 분리, 표 변환, Streamlit AppTest를 포함한다.
- 선택한 Hermes 회귀 101개: MemoryProvider, caller profile, fork scope, delegation toolset scope.
- Streamlit AppTest는 4개: 세 사용자 전환·인증 토큰별 이력, 과거 표 표시,
  원응답 보존, 근거 경고, 입력 비활성 상태를 확인한다.
- 통합 재실행: **205개 중 204 통과, 1 실패**. 실패는 기존
  `test_snapshot_reuse_and_fresh_lookup_keep_stable_prompt_and_tools`의 시스템 프롬프트
  동일성 검사였다. 단계 조회와 Snapshot 관련 값 검사는 통과했다.
- 동일 테스트 단독 재실행 **1개 통과**, 해당 파일 전체 재실행 **11개 통과**.
  앞선 통합 실행은 추가 회귀 2건을 넣기 전 **203개 전부 통과**였다.
- 따라서 전체 205개가 한 실행에서 모두 통과했다고 기록하지 않는다. 프롬프트 동일성의
  간헐 실패 원인은 아직 확정하지 못했다. 다음 실패에서 변경 구간을 볼 수 있도록
  요청 프롬프트의 unified diff를 assertion에 추가했으며 검사 자체는 완화하지 않았다.
- 필수 정적 검사: `scripts/check --staged --base ba9c08be` **19개 통과**.
- UI 의존성이 없는 기본 테스트 환경에서는 UI 모듈만 skip하도록 했으며,
  Streamlit을 설치한 환경에서 해당 4개 테스트를 다시 실행해 모두 통과했다.

기존 형식 보정 코드를 복원한 상태에서 새 표 회귀 테스트 4건이 실패하는 것을 확인했다.
기존 quality 검토 코드도 확인된 stage를 미확인이라고 표현하는 회귀 테스트에서 실패했다.
숫자·날짜·문서 ID·불확실성 표현 보존, 다열 변환, HTML 줄바꿈 제거를 검증하는 테스트다.

Streamlit 테스트는 `streamlit.testing.v1.AppTest`로 앱과 위젯을 실행하고 HTTP 응답을
fixture로 대체한다. 실제 브라우저의 픽셀 배치, 사내 프록시, SSO, 동시 접속 부하는 검증하지 않는다.
전체 Hermes 테스트를 실행했다는 의미도 아니다.

## 남은 문제

0. 시스템 프롬프트 동일성 회귀가 통합 실행에서 한 번 실패하고 단독·파일 재실행은 통과했다.
   원인이 미확정이므로 해결됐다고 보지 않는다. 운영 전 실제 요청의 프롬프트 지문과
   세션 경계를 관측하고 재현 조건을 찾아야 한다. Hermes 코어는 수정하지 않았다.

1. 근거 검사는 제한된 필드와 한영 패턴 기반이다. 복잡한 부정·번역·권고의 의미까지 검증하지 못한다.
   정정 뒤에도 모델 초안은 검토 대상으로 남는다. 경고가 없다고 전체 사실성을 보증하지 않는다.
2. 구조가 없는 문장을 의미 있는 표 열로 완전히 나누지는 않는다. 이 경우 원문을 유지하는
   순서/내용 표를 사용한다. 복잡한 병합 셀과 코드 블록까지 지원하는 Markdown 파서는 아니다.
3. 수정된 지침을 GPT-4o mini가 따르는지는 재실험하지 않았다. 이전 실제 결과는 원응답 형식
   준수 실패이며 로컬 보정을 모델 개선으로 계산하지 않는다.
4. 실제 실험은 질문 하나의 고정 순서 비교다. format과 focus를 따로 바꾸는 반복 실험,
   다른 사용자·과제 검증이 있어야 개인화 효과를 판단할 수 있다.
